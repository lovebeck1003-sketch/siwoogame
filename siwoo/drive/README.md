# infinite-drive — 무한 드라이브 🚗

끝없이 이어지는 도로를 목적 없이 달리는 힐링 드라이빙 게임.
점수도, 실패도, 도착지도 없습니다.

## 실행

```bash
# 저장소 폴더에서
python -m http.server 8765
```

브라우저에서 <http://localhost:8765/index.html> 접속.

> three.js를 CDN(unpkg)에서 불러오므로 인터넷 연결이 필요합니다.

## 조작

| 키 | 동작 |
| --- | --- |
| `W` / `S` | 가속 / 브레이크·후진 |
| `A` / `D` | 조향 |
| `Shift` | 부스트 |
| `Space` | 브레이크 |
| `C` | 시점 전환 (체이스 → 1인칭 실내 → 시네마틱) |
| `R` | 날씨 전환 (맑음 / 흐림 / 비 / 안개) |
| `T` | 시간 배속 (×1 / ×12 / ×60) |
| `F` | 헤드라이트 자동 / 켬 / 끔 |
| `H` | UI 숨기기 |

## 특징

- **무한 절차 생성** — 도로와 지형을 수식으로 만들어 냅니다. 저장된 맵이 없고, 같은 좌표는 항상 같은 풍경입니다.
- **바이옴 전환** — 초원 → 침엽수림 → 사막 → 설원 → 해안이 3.4km마다 서서히 섞입니다.
- **바다** — 해안 구간에서 도로 옆으로 바다가 펼쳐집니다. 파도가 출렁이고 햇빛이 반짝입니다.
- **하늘** — 대기 산란 근사로 그린 노을, 절차 생성 구름, 밤하늘의 별.
- **1인칭 실내** — 대시보드, 돌아가는 스티어링 휠, A필러, 룸미러가 있는 운전석 시점.
- **날씨** — 비, 안개, 흐림에 따라 시야·접지력·빛이 변합니다.

## 파일

- `index.html` — 3D 버전 (three.js). 파일 하나로 완결됩니다.
- `drive.py` — 초기 프로토타입 (pygame 2D 탑다운). `python drive.py`로 실행.
